StaffSync — HR Management System

StaffSync is a web-based Human Resource Management System designed to simplify employee management and HR operations.

Features

- Employee Management: Add, view, search, edit, and delete employee records.
- Attendance Management: Mark and view employee attendance.
- Leave Management: Submit and manage leave requests.
- Announcements: Share important updates with employees.
- Training & Development: Manage employee training programs.
- Employee Directory: Search and filter employee records.
- Reports & Analytics: View employee, attendance, and leave statistics.
- Authentication: Login system with role-based access.

Tech Stack

- Frontend: React, Vite, JavaScript, CSS
- Backend: Node.js, Express.js
- Database: MongoDB (if configured in the project)

Project Structure

StaffSync/
├── frontend/
├── backend/
├── package.json
└── .gitignore

Getting Started

1. Clone the repository:
   
   git clone https://github.com/harshitabarange40-cloud/StaffSync.git

2. Open the project folder:
   
   cd StaffSync

3. Install the root project dependencies if required:
   
   npm install

4. Install frontend dependencies:
   
   cd frontend
npm install

5. Start the frontend:
   
   npm run dev

6. Configure and start the backend separately using the instructions in "backend/package.json" and the required environment variables.
